# Method

## Order of sources

1. Issuer primary — annual report, 10-K / 20-F, statutory accounts, investor presentation dated on the slide
2. Regulator / exchange — ASIC, SEC EDGAR, ASX, company announcements
3. Official statistics — ABS, RBA, Fed, BLS, national statistical offices
4. Market print — exchange last, live book when needed
5. Secondary press — use only to find the primary URL

## Ledger columns

`as_of | metric | value | unit | source | locator | confidence | checked`

- high — primary document plus a page or exhibit locator
- medium — primary document, locator weak
- claim — marketing copy only

## Drift rule

A metric is in drift when two sourced rows for the same name disagree, or when an official page quietly rewrites a previously published figure. Keep both rows. Write one sentence naming the drift. Do not average them.

## Map rule

No analysis paragraph before at least three ledger rows exist for the question. If the rows cannot be found, the map is unknown plus the next document to open.

## Honesty rule

If we cannot refresh a name on a filing cycle, we do not sell Desk coverage of that name.
